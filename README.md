# 🚗 Used Car Price Prediction with Blockchain

A Machine Learning project that predicts the selling price of a used car and stores the prediction record using a simple blockchain.

## Features

- Used car price prediction
- Machine Learning model
- Streamlit web application
- Simple blockchain integration
- Stores car details and predicted price
- SHA-256 hashing

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit
- Blockchain
- SHA-256

## Project Flow

Car Details  
↓  
Machine Learning Model  
↓  
Predicted Price  
↓  
Blockchain  
↓  
Prediction Record
